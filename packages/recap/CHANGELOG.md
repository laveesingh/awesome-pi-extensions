# Changelog

All notable changes to `pi-recap` are documented here. This project follows
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] — 2026-10-21

Initial release. Requires Pi 1.3.0 and Node 22.19.0 or newer.

- Recap the last settled run in up to 3 bullets, generated by a configurable
  Pi chat model on its own `ModelRuntime` — separate providers and credentials,
  zero session state, so recaps can never enter context.
- Show the recap in a transient below-editor widget (pending → done/error),
  replaced each run; auto-recap skips tool-less short turns.
- Commands: `/recap`, `/recap hide`, `/recap model`, `/recap model clear`,
  `/recap auto on|off`, `/recap status`. Model choice, auto flag, and daily
  spend tally persist in `recap.json` in the agent dir.
- Every recap shows its own cost and today's total, since recap spend bypasses
  session accounting. Stale in-flight recaps are aborted and dropped by turn id.
